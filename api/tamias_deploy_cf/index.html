tamias-deploy-cf — materializes the Cloudflare registry: the Worker (index.js) + wrangler.toml (R2 binding), and the secret step. Runs wrangler deploy for the operator; requires their CF account.

The configured limits.max_upload is baked into wrangler.toml’s [vars] MAX_UPLOAD_BYTES at deploy time — the Worker enforces it server-side (the client preflight is cosmetic; this is authoritative).
