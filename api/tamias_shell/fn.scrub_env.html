pub fn scrub_env(c: &mut Command, vars: &[(String, String)])
Expand description

Give c a scrubbed environment: the allowlist values copied out of the parent’s env, then vars on top. Every child tamias spawns goes through this — tamias run (injected secrets in vars) and tamias serve’s PDP exec (empty vars) alike — so parent credentials can never leak into a subprocess.
