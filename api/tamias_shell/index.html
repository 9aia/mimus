tamias-shell — run a command in a working directory with extra env vars injected. Two modes back tamias run: a single string arg goes through bash -c (shell syntax, quoting, pipes); multiple argv are exec’d directly — argv[0] is the program, no shell involved. Resolved secrets arrive as (name, exposed-value) pairs and land only in the child’s environment.

Children do not inherit the parent’s environment (HIGH-2): a run starts from an empty env and receives only the small allowlist below — so TAMIAS_CF_TOKEN, CLOUDFLARE_API_TOKEN, TAMIAS_IDENTITY_FILE, TAMIAS_CONFIG, and any other parent credential can never leak into a child that shouldn’t hold it.
