pub fn init() -> TelemetryGuard
Expand description

Install the global subscriber: fmt + EnvFilter (RUST_LOG, default info) — the daemons’ long-standing behavior — plus the OTLP span layer when an endpoint is configured. Also installs the W3C trace-context propagator so trace_headers/server_span work regardless.

Keep the returned TelemetryGuard alive for the process’s span export; dropping it flushes and shuts the provider down.

A subscriber already installed simply wins — init never panics on a second call (each caller still gets its own guard).
