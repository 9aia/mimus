tamias-telemetry — the opt-in OpenTelemetry layer over the daemons’ tracing stack.

init builds the global subscriber every daemon main installs: the existing fmt + RUST_LOG (EnvFilter) logging, plus — only when an OTLP endpoint is configured — a tracing-opentelemetry layer exporting spans to a collector. With no endpoint the subscriber is exactly the tracing-only setup the daemons always used; TelemetryGuard is inert.

Env surface:

  • TAMIAS_OTEL_ENDPOINT — OTLP/HTTP base URL (http://collector:4318); /v1/traces is appended when absent, mirroring OTEL_EXPORTER_OTLP_ENDPOINT semantics.
  • OTEL_EXPORTER_OTLP_ENDPOINT / OTEL_EXPORTER_OTLP_TRACES_ENDPOINT — the standard vars also enable export (full OTEL_EXPORTER_* config: headers, timeout, compression, protocol).
  • TAMIAS_OTEL_SERVICE_NAME — service.name resource; falls back to OTEL_SERVICE_NAME, then "tamias".
  • OTEL_SERVICE_NAME / OTEL_RESOURCE_ATTRIBUTES — honored by the SDK’s env resource detector.

Propagation: init installs the W3C traceparent/tracestate propagator. trace_headers injects the current span’s context for outbound HTTP (hub→node); server_span builds the inbound http_request span with the remote parent attached. Both degrade to no-ops when export is off — injection emits no headers on an invalid context, and extraction yields a plain local-root span.

Functions§

enabled
true when an OTLP endpoint is configured — the flag callers use to log “telemetry on” at boot. Reads process env.
init
Install the global subscriber: fmt + EnvFilter (RUST_LOG, default info) — the daemons’ long-standing behavior — plus the OTLP span layer when an endpoint is configured. Also installs the W3C trace-context propagator so trace_headers/server_span work regardless.
record_response
Record the terminal response status onto a server_span — marks 5xx ERROR per the OTLP server-span convention.
server_span
The inbound http_request server span: method/target fields plus the remote parent extracted from traceparent/tracestate (no remote → a local-root span, which is the normal browser path). Record http.status_code (and otel.status_code = "error" on 5xx) onto it once the response is known.
trace_headers
W3C traceparent/tracestate headers carrying the current span’s context — inject into outbound requests (hub→node proxy calls). Empty when the current span has no valid OTEL context (export off or no span entered), so callers can apply unconditionally.
