Config port (tamias-config) — the tamias config model + format port.

YAML is the standard (tamias.yml / tamias.yaml); TOML (tamias.toml) is the supported alternative that parses into the same Config. Format impls live in tamias-config-yml / tamias-config-toml; the port never links them.

Structs§

Config
The tamias config — discovered as ./tamias.{yml,yaml,toml} (or TAMIAS_CONFIG/--file). store/cache roots feed the CLI’s Env (env vars win); registries/publish/search route the registry verbs; limits caps uploads/downloads.
EffectiveLimits
Fully-resolved limits — every knob concrete (defaults applied).
Limits
Byte-size limit knobs. Every field is optional — None inherits the next level of the resolution chain (per-package override → per-registry limits → global limits → built-in default; see Config::effective_limits).
Location
A store/cache location.
Publish
Publish-target routing.
Registry
A named registry.
Retention
Registry retention (P-024) — how many of a package’s most recent versions stay in the registry index after each publish. keep unset → no pruning (the default — pruning is opt-in).
Search
Search routing.
Signing
[signing] — optional package signing (ssh-keygen -Y, namespace tamias-package; see tamias-sign). Secret names never values: key/allowed_signers/official_signers are paths, key_env names an env var whose value is a key path — key material never lives here.
