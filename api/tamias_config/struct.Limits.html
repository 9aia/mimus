Struct Limits 

Source 
pub struct Limits {
    pub max_upload: Option<u64>,
    pub max_download: Option<u64>,
    pub packages: BTreeMap<String, Limits>,
}
Expand description

Byte-size limit knobs. Every field is optional — None inherits the next level of the resolution chain (per-package override → per-registry limits → global limits → built-in default; see Config::effective_limits).

packages maps a package name — or a * glob (foo*, *foo, *foo*, *) — to overrides for that package. It lives on the global limits (and may also appear under a registry’s limits for registry-scoped overrides); packages nested inside a package entry is ignored — overrides are one level deep.

§max_upload: Option<u64>

Per-package overrides — exact name or * glob → limits.
