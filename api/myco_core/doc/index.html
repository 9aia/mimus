Document models — the in-memory shapes myco-store-md parses project/ files into and emits back from. sections preserve file order; a name: None section is the unsectioned run before the first ## heading (only legal at index 0).

Structs§

BacklogDoc
BACKLOG.md — # Backlog plus optional ## sections of - T-NNN … items (no checkbox; items are Deferred).
DoneDoc
DONE.md — # Done plus optional ## sections of - T-NNN … items (no checkbox; items are Done or Cancelled — the terminal pair). The append-only archive todo done/todo cancel/item set --status done|cancelled land in — terminal tasks leave TODO.md but stay readable here (myco done list, item show); cancelled items keep their status: token so the archive distinguishes “finished” from “never doing this”.
ItemFile
One issues|proposals|adrs|plans/*.md file — TOML frontmatter in +++ fences + a free-form markdown body.
Section
A named run of items under a ## <section> heading.
TodoDoc
TODO.md — # TODO — <repo> plus ## <section> runs of - [ ] T-NNN … task items.

canonical_body
Canonical form of a free-text block — an item-file body, a handoff note: no leading blank lines, no trailing whitespace. Leading whitespace on the first content line survives — a full trim() would mangle a body that opens with an indented code block into a paragraph.
