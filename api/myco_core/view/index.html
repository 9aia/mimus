Module view 

Source
Expand description

Declarative views — filter → group → sort → limit → format as data (P-006). A ViewSpec is pure config; eval is a pure fn over &[Item]. Named views come from [views] in myco.toml layers; the built-in presets (board, epic, …) are the same engine’s shapes as data.

Semantics: OR within a filter list, AND across fields. Filters see top-level items only — children render with their parent.

eval
Evaluate a spec over repo-sourced items — the ViewSource::Repo universe. Every Scoped comes back untagged (repo: None); eval_scoped is the tagged form. kinds resolves the spec’s kind filter and group axis.
eval_scoped
Evaluate a spec over Scoped items — the ViewSource::Index universe feeds items tagged with their source repo. Filter, bucket, sort each bucket, truncate. Finite axes (status/priority/kind) yield every canonical bucket even when empty; renderers decide whether to show them. Named axes yield observed values only; UNGROUPED trails when reached.
