Expand description

The relationship an Edge asserts between two items. The *_by forms are the reverse views — extract only ever produces Handoff, Blocks, Supersedes, SupersededBy, Associated, and References; the index materializes the mirror at query time.

handoffs/<ID>.md exists — src == dst, an attachment marker rather than a link between items.

Blocks

§

BlockedBy

Reverse of Blocks — query-side only.

Supersedes

src declares supersedes: dst.

§

SupersededBy

src declares superseded_by: dst.

§

Associated

src declares links: dst — a kind-agnostic association (its plan, its proposal, …). Symmetric: the mirror is the kind itself, so incoming and outgoing land in one associated group.

§

References

src’s text mentions dst.

§

ReferencedBy

Reverse of References — query-side only.

Kind from a name token; None when unknown (forward-compat: a newer edge kind in an old index reads as “skipped”, not corrupt).

Source

pub fn mirror(self) -> EdgeKind

The reverse view: Blocks ↔ BlockedBy, Supersedes ↔ SupersededBy, References ↔ ReferencedBy; Handoff mirrors to itself. An incoming (other → id, k) edge reads as (id, other, k.mirror()) to the item being queried.

Source

pub fn extracted(self) -> bool

Can extract produce this kind? The *_by forms have no frontmatter to declare them (blocked_by exists only as a blocks mirror) — except SupersededBy, which is a real frontmatter field on ADR-shaped items.
