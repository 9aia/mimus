myco-core — pure domain for the PM ledger: item models, ID registry, state machine, deps. No I/O, no ports.

The numbered-slug domain (T-012/ADR-0004 ids, the owned open → claimed → in-progress → blocked → done state machine, actor IDs, document models, meta.toml counters) is file-spec agnostic — myco-store-md owns the markdown grammar.

date
time::Date helpers — myco serializes dates as YYYY-MM-DD everywhere (TODO lines, frontmatter, JSON).
doc
Document models — the in-memory shapes myco-store-md parses project/ files into and emits back from. sections preserve file order; a name: None section is the unsectioned run before the first ## heading (only legal at index 0).
handoff
Handoff entries — the handoffs/<ID>.md records that carry resumable state between sessions (myco handoff / myco resume, sepia on the boundary).
id
Typed item ids in one namespace — T-012 tasks, I-003 issues, P-002 proposals, ADR-0004 ADRs, PL-001 plans, plus user kinds declared via [[kinds]] (P-008).
item
The work item — shared shape for TODO/backlog line items and issue/proposal/adr/plan file metadata (ItemFile adds a body).
kind
The kind table — [[kinds]] in myco.toml layered over the compiled-in prelude (P-008).
ledger
The ledger — TODO.md + BACKLOG.md held together: task items move between the two docs on status changes (deferred parks, done deletes). Pure doc manipulation — loading/saving through a Store lives in myco-ops.
meta
meta.toml model + the pure id-allocation logic.
priority
Item priority. Frontmatter and pri: line tokens use the short forms low|med|high|crit; serde (JSON views, wire) uses the full kebab names ("medium"). Read accepts both — lenient read, strict canonical write.
refs
refs — the pure edge scanner behind the link index (P-005).
status
Item status — the owned state machine.
view
Declarative views — filter → group → sort → limit → format as data (P-006). A ViewSpec is pure config; eval is a pure fn over &[Item]. Named views come from [views] in myco.toml layers; the built-in presets (board, epic, …) are the same engine’s shapes as data.
walk
Status-transition walks — the shortest legal path from → to through the state machine (BFS over Status::transitions).

Enums§

ConfigVerb
A [verbs.<name>] config-declared verb (P-007). Both kinds are read-only by construction: an alias bakes argv for a read-only built-in; a view-emit binds a ViewSpec to an emit mode. Mutations stay builtin — the state machine, id alloc, locking and commit semantics aren’t config data.
EmitMode
How a view-emit verb renders its evaluated spec.
LedgerMode
A repo’s ledger relationship in the org index — the ledger key in repos.toml (legacy registry) or [index] ledger in myco.toml (P-026). Absent → LedgerMode::Local, the conventional reading.
