Struct ItemKind 

Source 
pub struct ItemKind { /* private fields */ }
Expand description

The kind of work item an ItemId addresses — data since P-008: the prefix is the identity, pad is the canonical emit width (T-007 → 3, ADR-0004 → 4). The five builtins exist as associated consts — ItemKind::Task and friends keep working — and crate::KindSpec carries the rest of what used to be enum semantics.

PartialEq/Hash compare the prefix only — pad is a display hint, so S-0007 (spec pad 4) and a hand-typed S-7 (pad hint 3) are the same id. Ord is builtin-declaration order, then prefix-alphabetical for user kinds.
