Fields§

§id: ItemId

Typed id — determines kind, sort, filename.

§title: String

One-line summary. No ·, no newlines in line-grammar contexts (enforced at emit, not here — Item is a value, not a validator).

§status: Status

Lifecycle state — transitions are validated by the caller via Status::transition_to.

§priority: Priority

pri: — defaults to Priority::Medium.

§owner: Option<Actor>

owner: — devin, human:luis, …

§labels: BTreeSet<String>

#labels — a sorted set, duplicates impossible.

§blocks: BTreeSet<ItemId>

blocks: — ids this item blocks. Sorted set.

§links: BTreeSet<ItemId>

links: — ids this item is associated with (its plan, the proposal that spawned it, …). Kind-agnostic and symmetric — a declared edge, not a prose mention. Sorted set.

§created: Option<Date>

created: — YYYY-MM-DD when known. Absent (not null) in JSON — every other Option field skips the same way.

§note: Option<String>

Free-form note — handoff/resume payload (phase 6).

§superseded_by: Option<ItemId>

superseded_by: — the item that replaced this one (ADRs).

§supersedes: Option<ItemId>

supersedes: — the item this one replaces (ADRs).

§epic: Option<String>

epic: — the epic (named delivery grouping) this item belongs to. Line token epic:<name>; a group name, not a label — one per item.

§milestone: Option<String>

milestone: — the milestone this item targets. Line token ms:<name> (kept short — lines stay readable).

§due: Option<Date>

due: — the calendar date this item is due, YYYY-MM-DD (timezone-free, like created:).

§estimate: Option<u32>

est: — relative size in points (MAX_ESTIMATE bound). Points, not hours — teams define their own scale.

§cycle: Option<String>

cycle: — the iteration/sprint this item is scheduled in. A group name like epic:/ms: — existence is a check concern, not a parse one (free-form names are legal).

§children: Vec<Item>

Nested sub-items — the - [ ] lines indented under this one in TODO.md/BACKLOG.md. Children are full items: same metadata, same state machine. Depth is arbitrary (one level is the recommended shape); done/defer act on the whole subtree. Empty for file-backed kinds — children only exist in the line grammar.
