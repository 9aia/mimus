One [[kinds]] entry — or one prelude row.

Fields§

§name: String

Config/view vocabulary — task, spike.

§prefix: String

Id prefix — T, S. [A-Z][A-Z0-9]*, ≤ 15 bytes.

§storage: Storage

doc (ledger lines) or dir (item files).

§dir: Option<String>

dir-storage subdirectory — defaults to <name>s (spike → spikes/). Unused for doc kinds.

§file_prefix: Option<String>

Filename prefix before the number — defaults to name. Empty string is meaningful: ADR files are adrs/0004-*.md.

§states: Vec<Status>

The statuses this kind may carry — defaults to the full machine (today’s behavior for every kind).

§done_state: Status

The status that counts as resolved — done removes doc lines and marks dir items resolvable. Defaults to done.

§supersede: bool

superseded_by:/supersedes: frontmatter is meaningful for this kind (ADRs).

§resolve_verb: bool

The kind has a resolve-style verb (issue resolve) — declaration only in v1; no verb reads it yet.

§zero_pad: usize

Canonical zero-pad in emitted ids — T-007 is 3, ADR-0004 is 4. Defaults to 3.
