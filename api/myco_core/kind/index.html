Expand description

The kind table — [[kinds]] in myco.toml layered over the compiled-in prelude (P-008).

ItemKind (in id.rs) is the id identity — the prefix an ItemId carries. KindSpec is the declaration — name, storage shape, state list, zero-pad — and KindTable is the resolved set: the five prelude kinds plus whatever [[kinds]] declares. Missing config = the prelude alone, so zero-config behavior is today’s.

Merge semantics follow the config-verbs rule: a [[kinds]] entry named like a prelude kind shadows it (restating the prelude verbatim is a no-op; init seeds it commented) — but a builtin’s prefix is identity-locked, since changing it would reinterpret every existing id. New names must not collide on name or prefix.
