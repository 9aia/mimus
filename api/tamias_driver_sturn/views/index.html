Module views 

Source
Expand description

views — the driver’s manifest: every ViewSpec plus the query resolvers that feed them.

Read path: all data comes from crate::data::Snapshot — a single fold of the resolved repo’s refs/sturn/wal/* logs per wire op, through sturn-wal-git/sturn-claim/sturn-ask exactly like the sturn CLI verbs. Nothing here proxies the sturn binary or sturn serve-equivalent surface: the reads are in-process ODB/ref walks, and keeping the driver a pure reader means it can never mutate coordination state.

Verb → view mapping:

sturn surfacepavo view
sturn claimssturn:claims table
sturn log / sturn diffsturn:ops table
sturn asks [--all]sturn:asks table
sturn ws ls + WAL depthsturn:workspaces table
sturn sub <topic> vocabularysturn:topics table
repo/WAL/claim digeststurn:status kv
