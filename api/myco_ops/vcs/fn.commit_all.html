pub fn commit_all(repo: &Path, msg: &str) -> Result<()>
Expand description

git add -A -- . && git commit --allow-empty -m <msg> — the auto-commit-per-verb path writes files first, then this. The stage is scoped to repo (-- .): when repo is a plain subdirectory of a bigger repo rather than a real worktree, changes elsewhere aren’t swept into the ledger commit (the port’s stage_all is a whole-tree add -A — too broad here). A bare commit could still pick up foreign staged changes, so those are refused rather than committed under our message (a commit -- <pathspec> alternative can’t express the first commit — the pathspec must match known files). --allow-empty keeps no-op verbs honest in the audit trail.
