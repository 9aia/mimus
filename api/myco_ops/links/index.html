links — the invalidation driver for the link index (P-005).

One sync walks a worktree’s *.md files, diffs them against the index’s stored FileStamps (mtime+size precheck, then the content fingerprint), re-derives edges for the dirty set only, records each file’s new edge set atomically, and sweeps records whose files vanished. Unchanged files are never even re-read, let alone re-parsed.

The driver is grammar-free like the rest of ops: extract maps (rel path, source) to edges and is supplied by the front-end that owns the file spec (the CLI’s links module for index rebuild; the TUI keeps its own in-memory graph). A file that fails extraction is stamped with zero edges — a broken file is “processed, nothing declared”, not a retry loop — and reported in SyncReport::errors.
