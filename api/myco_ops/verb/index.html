Config-declared verbs — [verbs] from merged config layers (P-007). Resolution mirrors view.rs: config files are I/O so the merge lives here; the verbs themselves are executed by the front-end (cli). The builtin surface is injected — ops doesn’t know the registry, callers hand it in like ConfigLoader.

Config verbs are read-only by construction: an alias may only target a read-only builtin, and a view-emit can only evaluate a spec. Collisions mirror view-shadowing except the builtin wins — a config verb can never hide the stable surface.
