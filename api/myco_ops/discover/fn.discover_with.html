discover with the repo index available — the last-resort fallback for the org-ledger pattern: when plain discovery fails inside a registered repo that has no ledger of its own, the org entry’s worktree answers instead. None (or an unreadable index) keeps discovery exactly as strict as before — unregistered repos still fail.
