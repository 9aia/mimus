Module history 

Source
Expand description

Undo journal — myco-history.json in the repo’s git common dir (<main>/.git, shared by every worktree). It records only the future: commits undo moved away from that redo can still restore. The ledger’s linear commit chain stays the “past” — the journal is disposable derived state, never committed to project/.

Each entry anchors on base: the HEAD position it was undone from. Redo fires only while HEAD still equals the top entry’s base — any commit, pull, or manual git op breaks the anchor and the stack self-clears on next read. No hooks into commit paths; the HEAD check is the invalidation.

Robustness: a missing or corrupt file reads as empty history (redo refuses, undo rewrites it); saves are tmp+rename so a crash mid-write can’t leave a torn journal; entries are shape-validated on load and the stack is capped.
