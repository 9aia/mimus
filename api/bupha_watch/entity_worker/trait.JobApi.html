The narrow synchronous port the claim loop speaks. EntityJobApi adapts hypha_node_api::EntityApi (async, ureq-backed); tests substitute an in-memory fake.

fn emit_completed(&self, _job: &EntityJob, _result: &str)

Best-effort terminal notification — the worker POSTs a typed ci.job.completed event to the node’s event-ingest route so campaigns can react (pr-heal). Called only after a successful ci.complete; failures are logged, never propagated — the settle already happened. Default no-op.
