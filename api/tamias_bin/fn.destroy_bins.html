Expand description

Destroy an entry’s declared bins — remove the bin-dir artifacts this package owns, leave foreign/other-package files alone.

entry_dir is Some while the store entry exists (enables the copy-platform byte-compare ownership check); None after tamias remove — symlinks are still identifiable through the alias, scripts through their marker, copies are left (can’t prove ownership without the payload).

§Errors

Filesystem failures; unresolvable payload decls are skipped (the package is going away anyway).
