Best-effort teardown of everything deploy_bins + unlink_payload_bins put on the bin dir — declared bins[] first (their payload links share the alias the unlink removes), then the legacy bin/ payload. Both halves run even when one fails; errors are joined into one Error. Call while the store entry still exists so copy-platform byte-compares can read the payload.
