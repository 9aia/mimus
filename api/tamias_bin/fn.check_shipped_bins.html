Expand description

Pack-time conformance gate for bins[].payload decls — every declared payload must have a shipped counterpart for some platform. The install host’s triple is substituted at deploy time (resolve_payload_bin), so pack time can’t pin one: a tools/bin/<triple>/<rest> decl is satisfied by <rest> under any shipped platform dir, while a portable tools/bin/<file> decl needs that literal file (mirroring the resolver’s rules — substitution only applies to paths deep enough to carry a triple segment).

Catches authoring typos at tamias pack/publish instead of install time. check_bins remains the install-side gate — it additionally enforces the host-platform rule, which is host-dependent and must not run at pack time.

§Errors

Fails naming each decl with no shipped counterpart.
