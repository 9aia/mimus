Expand description

Resolve a bins[].payload declaration to (abs_src, rel) — the file inside payload_root and its payload-relative path with the host triple substituted (what alias-relative link targets use).

Resolution order:

  1. the declared path verbatim (tools/bin/<host>/<file> on the matching host, or a portable tools/bin/<file>);
  2. tools/bin/<declared-triple>/… with the triple segment replaced by [tamias_driver::target_triple] — one manifest, every host;
  3. error naming what tools/bin/ actually ships.

§Errors

Fails when neither form exists or tools/bin/ is unreadable.
