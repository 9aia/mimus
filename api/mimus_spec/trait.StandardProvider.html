Expand description

An org-tool predicate provider (P-002) — owns one providers.<ns> namespace and evaluates its claims table against a repo. Implementations may shell out to their tool’s CLI (bupha status --json-style) or inspect the tree directly; the port stays I/O-light by contract.

claims is the raw [providers.<ns>] table from the spec — untyped on purpose: the provider owns its claims schema, and unknown keys inside it are the provider’s problem, not the spec model’s. Returned violations keep whatever spec/ severity the provider sets; the evaluator passes them through verbatim.
