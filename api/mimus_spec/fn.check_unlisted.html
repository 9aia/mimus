Expand description

unlisted check against the union of a matched spec set — the composed standard. A tracked file is a violation only when no matched spec covers it; per-spec check_repo would double-report files a sibling spec legitimately whitelists. Severity is the strictest among specs; spec names the strictest spec (the violation belongs to the composition, not one pack).
