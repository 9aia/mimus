pub fn target_triple() -> &'static str
Expand description

The rustc target triple this build was compiled for (x86_64-unknown-linux-gnu) — captured at compile time by build.rs (cargo:rustc-env), so it always names a real cargo target even where std::env::consts can’t reconstruct the vendor/os/env spelling.

This is the selector for a payload’s drivers/bin/<triple>/ dir — see register_bundled_drivers.
