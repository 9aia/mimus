Expand description

views — the driver’s manifest: every ViewSpec plus the query resolvers that feed them.

Read path: every query resolves a crate::data::Plane (params base/config, else the watcher’s own config discovery) and reads history.jsonl / queue.json / the systemd units — see data.rs. A failed read degrades to an {"error": …} or {"note": …} payload inside an ok:true response, matching the sibling drivers’ contract.

Surface mapping:

pavo viewdata
bupha:statusplane digest — base, queue kind, counts, unit states
bupha:runshistory.jsonl tail (repo/limit params)
bupha:queuequeue.json pending/running per key
bupha:reposlatest history record per repo/job key
bupha:servicesystemctl --user state of watch/worker units
