host — engine-host mode: run the watcher pipeline in-process so deployed provider units exec this driver binary instead of a cargo-installed bupha (ADR-0006: no user-facing bupha CLI on the host path; bupha T-052).

Loads the operator config deploy wrote — --config <path>, else ~/.config/bupha/bundles/<name>.toml (--name required then) — and blocks in bupha_watch::watch: trigger listener + queues + runner + status sinks, identical to bupha watch. --dir is accepted (tamias’s dispatch contract) but unused — the payload’s fleet.toml only matters at deploy time.

§Errors

Fails on a missing --config/--name or an unloadable config; once running, config errors inside watch exit the process like the CLI’s did.
