pub fn worker(f: &Flags) -> Result<String, String>
Expand description

worker — the ci-job consumption loop (P-002 §4.1): poll kind="ci-job" entities on a hypha/peregrin node, ci.claim the pending ones this box’s [worker] labels cover, run them through the same bupha-watch pipeline host uses (worktree → runner → status sink), ci.renew on the run ticker, ci.complete with the result. This is the second service a fleet deployment runs alongside host — the watcher ingests pushes (standalone mode) while workers execute jobs the entity plane hands out; in peregrin-hosted mode the plane lives on the node and host isn’t needed at all.

Node endpoint resolution: --node → BUPHA_WORKER_NODE → [worker] node in the operator config. Credential: --node-token-env / [worker] node_token_env names a secret resolved through the usual chain (env → cuora → keyring → ~/.config/bupha/env); BUPHA_NODE_TOKEN is a direct-token escape hatch; neither set = unauthenticated (dev nodes).

§Errors

Fails on a missing --config/--name, an unloadable config, a missing node endpoint, or an unresolvable token NAME; once running, poll errors back off and retry.
