myco-tui — interactive board TUI for a repo’s project/ worktree, or for the cross-repo index universe when --view names a source = "index" spec (org-*).

Index boards: the crate stays index-impl free — the caller injects an OrgLoader that yields each registered repo’s slice (myco ui wires the redb load_fresh). Rows render repo:ID; a task verb on a row opens that repo’s store under the same lock→mutate→commit discipline.

A thin front-end over myco-ops: every mutation goes through the same ledger ops the CLI verbs use, so writes and commits are identical to myco todo done et al. Ported from pm’s Bubble Tea reference (9aia/pm, docs/tui.md there) — the keymap is vim-style: j/k move, h/l/tab/shift-tab/1/2/3 boards (tab cycles, wrapping), Space/dd done and u/U undo/redo (all ask y/n first), D defer, p promote, Alt+↑/↓ reorder, a add, / filter, : command line (:q :w :e :<id> :set id), Enter/→/ double-click open the preview (j/k scroll, ←/esc back — ← pops a drill-down stack of the boards/items you opened through), E $EDITOR, R reload, ? help, q/Ctrl-C quit — plus mouse: the wheel scrolls, a click selects an item row or a board tab, a double-click opens the row. The board also auto-reloads: an OS filesystem watcher (inotify / kqueue / FSEvents via notify) covers the project/ worktree in repo mode — or the index data dir + each repo’s worktree on index boards — and wakes a content fingerprint scan on change, with a slow periodic scan as fallback. Writes from other myco invocations, git pull, or hand-edits show up without a keypress.

Structs§

OrgRepo
One registered repo’s slice of the index universe — what an index-sourced view (--view org-*) loads instead of the repo store. worktree is where a mutation on this repo’s items opens its own store.

Functions§

run
Launch the TUI. dir/root are the same discovery overrides the CLI takes; no_commit suppresses the per-mutation commit. view names a declarative view (builtin preset or [views.<name>] config entry) whose filter narrows every board’s item source; a source = "index" view swaps the repo store for org’s cross-repo universe (required then — myco ui supplies it).

Type Aliases§

OrgLoader
Loads the index universe — injected by the composition root (myco ui wires the redb index here; the TUI itself is impl-free). Called at open and on every reload (:w/R).
