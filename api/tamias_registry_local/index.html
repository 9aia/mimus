tamias-registry-local — a directory registry: published packages as .tgz blobs plus an index.json. It can also be served over a tiny HTTP surface (GET /<key>, PUT /<key>) so a remote client (and the Cloudflare Worker, which speaks the same protocol) can publish/read.

Functions§

serve_http
Serve root over a tiny blocking HTTP surface until the process stops. GET /<key> reads a blob; PUT /<key> writes one. The registry root is the blob namespace (paths sanitized — no traversal).
serve_http_with_limits
serve_http with an explicit upload cap — the configured limits.max_upload (flag > config > this default).
