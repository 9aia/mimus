The pure workflow core — public so a sibling dialect (gitlab) or tooling can reuse parse/select/expand without the runner. plan — the pure workflow core: .github/workflows/*.yml text in, validated Job plans out. No I/O — the runner hands in YAML strings and an Event (ref + changed files); every construct outside the v1 subset is an explicit error naming the YAML key.
