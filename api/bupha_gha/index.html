bupha-gha — runner impl that executes .github/workflows/*.yml natively: GitHub Actions as bupha’s first CI dialect. The pushed sha’s detached worktree is the workspace; workflows are parsed by the pure plan core, rendered to bash by script, and spawned as one child the watcher waits on.

The supported subset and its hard boundaries live in the crate README — anything outside it is a loud error at spawn time, never a silent skip.

Naming (T-054): bupha-gha / runner.kind = "gha" name the workflow-dialect direction — bupha reads .github/workflows/*.yml and executes it. The opposite direction — bupha registering as a GitHub self-hosted runner speaking the actions/runner broker protocol (runs-on: [self-hosted, bupha]) — is reserved the name gha-runner (crate bupha-gha-runner); never reuse bare gha for it.
