Open a registry: value is a registries config name first, then a raw dir/http ref (parse_registry_ref). None → the env / default local root at registry_root. Callers resolve the routing defaults (publish.default/search.default, TAMIAS_REGISTRY env) into value before calling — env wins over config, flag over env.

package (the manifest name on publish) selects per-package limit overrides; the resolved [tamias_config::EffectiveLimits] are handed to the adapter (with_max_upload), which enforces them — the packed-tarball size probe runs post-pack/pre-upload inside publish, so an over-limit payload never reaches the wire or the index. keep is the per-invocation retention override (publish --keep) — None resolves retention.keep from config (global → per-registry → per-package, see effective_retention). It only matters on the publish path; search-built registries carry it inertly.
