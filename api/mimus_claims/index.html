Crate mimus_claims 

Source
Expand description

Claim extraction — find factual assertions in prose, comments, and cards. Conservative by design: extracting a claim that isn’t one produces noise downstream (see ADR-0001).

Functions§

extract
Extract claims from document text. v1 mines backtick-quoted spans — the highest-precision source: writers quote exactly the things they assert (paths, commands, names).
extract_comments
Extract assertive comment lines as Behavior claims — the code↔code consistency surface: comments that assert things the code may or may not do. //, ///, //!, # lines; capped.
