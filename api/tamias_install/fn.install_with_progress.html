Install reference, reporting Progress events to report.

§Errors

Fails on an unparseable ref, a planning/fetch failure, a missing or invalid package manifest, refused bundled drivers (no consent), a missing driver for a non-files content type, a failing driver, or a store-commit failure. Nothing is committed to the store on failure; the content-addressed fetch-cache entry stays.
