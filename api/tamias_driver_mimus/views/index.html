Module views

Expand description

views — the driver’s manifest: every ViewSpec plus the query resolvers that feed them.

Read path: crate::data::Snapshot resolves the repo root + mimus.toml once per wire op. status/rules/audit read files in-process (config, rules/*.toml, .kuda card provenance); violations shells out to mimus report --format json — the check pipeline is the critic’s authority and not something a view driver should fork.

Verb → view mapping:

mimus surfacepavo view
mimus report (violations)mimus:violations table
mimus audit (card trust)mimus:audit table+kv
rules/*.toml convention rulesmimus:rules table
config/index/cache digestmimus:status kv

mimus persists no verdicts or history — there is no mimus:verdicts/mimus:history view to build. mimus:status says so.
