Module register 

Source
Expand description

Registration: turn a short-lived registration token (or a PAT that mints one) into credentials that last — the equivalent of what config.sh writes to .runner.

Three calls, then the private half of a generated RSA key stays in the credentials file: it signs the JWT assertions that buy access tokens and unwraps session keys, so the registration token is needed once and can expire.
