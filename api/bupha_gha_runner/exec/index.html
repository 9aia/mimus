Source
Expand description

Job execution: expanded JobMessage steps → spawned shell children in a per-job workspace. Script steps run through bash/sh, actions/checkout clones the repository, and the $GITHUB_* file commands (GITHUB_ENV/GITHUB_OUTPUT/GITHUB_PATH) the protocol requires are implemented per job.

Everything unsupported fails the step loudly — a node action we cannot run is a red step naming the action, never a silent skip.
