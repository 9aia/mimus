Wire types for the Actions runner protocol — the shapes the broker, the run service and the results service exchange.

Two JSON dialects appear on the wire and are not handled here: data-encoded contexts and token-encoded step fields are unwrapped by crate::encoding before these types see them. Field names follow the service: camelCase almost everywhere, with the run-service endpoints (acquirejob/completejob/renewjob) spelled the same way.
