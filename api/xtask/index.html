xtask — repo chores. cargo xtask <verb> via the alias in .cargo/config.toml.

  • check — cargo fmt --check + cargo clippy -D warnings
  • test — cargo nextest run when installed, else cargo test
  • coverage — cargo llvm-cov (HTML → target/llvm-cov/html); extra args pass through, e.g. --fail-under-lines 100
  • install — release-build tamias-driver-myco → ~/.cargo/bin (the myco command itself is the tamias pack’s generated bins[] shim — cargo xtask pack + tamias install ./libraries/myco)
  • pack — stage libraries/myco driver payload (release tamias-driver-myco → drivers/bin//)
  • site — build the docs site (docs/ worktree, VitePress)
