tamias-source-http — the tarball ref kind + source: http(s)://….tgz|.tar.gz GETs, verified against the optional #sha256: pin, unpacked into the fetch dir. The tarball’s sha256 is the content key (sha256-<hex>), so a pinned ref + warm cache never touches the network — the air-gapped path.
