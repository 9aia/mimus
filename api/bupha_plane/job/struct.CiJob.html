Expand description

One ci-job entity — the indexDoc of kind="ci-job" (P-002 §1). Serialized camelCase on the wire; id is derived, never trusted from the payload (#[serde(skip)] both ways).

Fields§

§id: String

ci:{key}:{sha}:{attempt} — deterministic, so webhook replays dedup for free (create is idempotent on this id).

§key: String

WatchedRepo.key — owner/name[:job]; the queue lane id.

§repo: String

Status/forge repo — status_repo, defaults to the key’s repo part when absent.

§git_ref: String

Push.git_ref — wire name ref.

§sha: String

Push.sha — is_valid_sha’d at the trust boundary.

§event: String

Push.event — closed set "push"|"pull_request".

§sender: String

Push.sender — forge-attested.

§delivery_id: Option<String>

Forge delivery id — audit/dedup only (the entity id already dedups replays).

§queue: String

Resolved queue policy — closed set "latest"|"all".

§runs_on: Vec<String>

Resolved label requirements (job → repo → []); a claiming worker’s advertised capabilities must cover them.

§runner: Value

Resolved runner config verbatim — token_env is a NAME, safe to store. cancel_running inside it conflicts with all.

§context: String

Status context label — defaults to ci/bupha[/<job>].

§max_attempts: u32

repo.retry + 1 resolved at ingest; 1..=MAX_ATTEMPTS.

§attempt: u32

1-based attempt — auto-retry spawns a NEW entity at +1.

§state: JobState§enqueued_at: String

RFC3339 — when the job (re-)entered the pending lane.

§claimed_by: Option<String>

Worker id (<node>/<pid>) once running.

§fence: u64

Fencing token — bumped on every claim; renew/release/complete must present it.

§lease_expires_at: Option<String>

RFC3339 lease expiry — lazy-swept back to pending.

§superseded_by: Option<String>

Sha that superseded this job (latest sweep / all eviction).

§cancel_requested: bool

ci.cancel on a running job — the worker’s renew loop polls and kills its child.

§result: Option<String>

Terminal outcome — success|failure|cancelled|error| superseded.

§description: Option<String>

Short outcome text (status description).

§log_ref: Option<String>

Optional pointer to run logs/artifacts.

§started_at: Option<String>§finished_at: Option<String>§created_at: String

Plane bookkeeping — not part of the P-002 indexDoc contract, skipped on serialize so indexDoc matches the spec exactly.

§updated_at: String
