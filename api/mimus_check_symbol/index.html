Symbol adapter — symbol claims resolve against a kuda index. Consumes the index file format (.kuda/index.sqlite), not the kuda crates — the schema is the contract.

Evidence rules: a claim found in the index is verified; a namespaced claim (mod::Sym) absent from it is refuted; a bare identifier absent from it is silence — it may simply be external (std/dep) and unproveable.
