pub fn install(&self, spec: &ServiceSpec) -> Result<PathBuf, Error>

Write the wrapper .cmd + task .xml, then schtasks /create /tn <name> /xml <file> /f (registers or overwrites). Returns the task XML path.

§Errors

Error::Failed on an invalid name/spec field, a .cmd quoting failure, an empty exec argv, or a write/schtasks failure. On non-Windows the default runner fails at the schtasks step — the rendered files are still left on disk.

Source

pub fn daemon_reload(&self) -> Result<(), Error>

No-op kept for parity with the systemd backend’s daemon-reload: schtasks /create registers immediately, so there is nothing to reload.

§Errors

Never — always Ok.

pub fn enable(&self, name: &str) -> Result<(), Error>

schtasks /change /tn <name> /enable — tasks are created enabled, so this is mostly a re-assert after an external disable.

§Errors

Error::Failed on an invalid task name; propagates the runner failure.

pub fn start(&self, name: &str) -> Result<(), Error>

Source

pub fn stop(&self, name: &str) -> Result<(), Error>

schtasks /end /tn <name> — terminates the task’s process. Unlike systemd’s cgroup stop this may leave grandchildren behind.

§Errors

Error::Failed on an invalid task name; propagates the runner failure.

Source

pub fn restart(&self, name: &str) -> Result<(), Error>

Best-effort restart: /end (ignored when the task isn’t running — systemd restart starts a stopped unit too) then /run.

§Errors

Error::Failed on an invalid task name; propagates the /run failure.

Source

pub fn status(&self, name: &str) -> Result<(), Error>

schtasks /query /tn <name> /v /fo list — best-effort; the runner captures output, so this mainly surfaces “does the task exist” via the exit status.

§Errors

Error::Failed on an invalid task name; propagates the runner failure.

Source

pub fn logs(&self, name: &str) -> Result<(), Error>

Best-effort status for one task — same as Self::status.

§Errors

Error::Failed on an invalid task name; propagates the runner failure.

Source

pub fn logs_with( &self, names: &[String], _lines: u32, _follow: bool, ) -> Result<(), Error>

Best-effort “logs” over one or more tasks — Task Scheduler keeps no per-task log, so this runs schtasks /query per task name (lines/follow are accepted for signature parity and ignored). Returns an error on an empty name list.

§Errors

Error::Failed on an empty/invalid name list; propagates the first runner failure.

Source

pub fn uninstall(&self, name: &str) -> Result<(), Error>

schtasks /delete /tn <name> /f (best-effort — a missing task must not fail uninstall) + remove the wrapper .cmd and task .xml.

§Errors

Error::Failed on an invalid task name; propagates the file removal failure.
