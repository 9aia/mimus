Module ops 

Source
Expand description

Engine ops — cli.<verb> wire queries dispatch into the myco engine lib through this binary’s own run verb: each call re-execs tamias-driver-myco run <argv> with the request’s repo as cwd, so myco::dispatch writes to the child’s captured stdout and never touches the serve loop’s ndjson stream — and every mutation keeps the engine’s own write-path semantics (per-verb commit, Actor: trailer, worktree lock).

ops answers the ops manifest as JSON — derived from the engine’s own [myco::registry::VERBS] table, so a verb can’t exist on the CLI and be missing here. Unbounded verbs (serve, ui) are deliberately not ops — they never return, so they live in surfaces instead: surface drivers (tamias-driver-cli / -mcp, the pavo-driver-kit surface layer) expose them as streaming subcommands.

Wire params carry each verb’s declared param schema: arg = positional, opt = --name <v>, flag = --name — the contract pavo-driver-kit’s surface layer renders args from.
