Module overlay

Expand description

include: overlay composition. A payload deep-merges over its bases: local wins, dicts merge per-key, arrays concat local-first. Earlier include: entries outrank later ones. Conflicting .yaml/.yml/ .json files merge document-wise; other files resolve whole-file with the higher priority winning.

overlay composes resolved base dirs under a local payload — tamias-install runs it post-manifest/pre-driver on install (the store record’s digest covers the composed tree) and tamias-publish runs it read-only when packing (flatten-by-default). payload_root finds the manifest dir inside a fetched tree; find_store_entry matches an include: entry against installed store entries — the name half of base resolution both surfaces share.

Functions§

find_store_entry
Match an include: entry against installed store entries. An entry names a base three ways: the full label (@scope/name@version or name@<sha12>), the scoped name (@scope/name), or the bare name (name — scope-agnostic, so several installs sharing it is an ambiguity error, same rule as Store::find).
merge_values
Deep-merge high over low — the overlay merge rule exposed for callers that fold partial documents themselves (deploy-time operator overrides, driver-side config merges): dicts merge per-key, arrays concat high-first with id-keyed dedupe, everything else takes high.
overlay
Compose local over bases into dest. bases list the include:d payload dirs in manifest order — earlier includes win over later ones, local wins over everything.
payload_root
The payload root inside a fetched dir — dir itself when it holds a manifest, else the single child dir it wraps everything under.
