Expand description

What an install records — the provenance list/info/verify report on.

Fields§

§name: String

Bare package name (from the payload manifest).

§scope: Option<String>

Scope, when the package is namespaced (@scope/name).

§version: Option<String>

Author-declared version, when the manifest carries one.

§kind: Option<String>

Content type (peregrin-bundle, myco-config, …).

§source_ref: String

The exact source ref the install was invoked with.

§resolved: String

What the source resolved to — commit sha or sha256:<hex>.

§digest: String

sha256:<hex> of the unpacked payload — verify recomputes it.

§signature: Option<String>

Armored ssh-keygen -Y signature over the provenance anchors (name/scope/version/digest — see tamias-sign), when the source carried one (registry index entries today). verify re-checks it against allowed_signers.

§signer: Option<String>

The verified signing principal (@scope/name or bare name) recorded at install — None on records that predate trust-tier reporting or carried no signature. tamias verify re-derives it live when absent.

§trust: Option<String>

The tamias-sign trust-tier wire spelling (official / signed / pinned / unpinned / bad) at install time — None on older records; surfaces re-derive lazily.

§installed_at: u64

Unix seconds at install time.
