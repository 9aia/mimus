Tar archives — bundle pack writes .tgz; the http/fs sources unpack tarballs here. Paths sanitize on unpack (no absolute/.. escapes), the executable bit keeps.

Constants§

DEFAULT_MAX_ENTRIES
Default cap on tar entry count — 100k entries bounds inode/dir spam from a tiny archive.
DEFAULT_MAX_UNPACK_BYTES
Default cap on total unpacked bytes — 2 GiB. max_download bounds the compressed blob only; a small .tgz can expand without bound, so every untar path enforces this ceiling.
