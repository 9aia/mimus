Bounded subprocess execution — Command::output blocks forever on a hung child (a stalled git remote, a wedged driver), so callers that can be reached by untrusted refs go through output_with_timeout.

Functions§

output_with_timeout
cmd.output() with a wall-clock bound. stdout/stderr are drained on threads while the child runs, so a chatty child can’t deadlock on a full pipe; on timeout the child is killed and waited on before the error returns. Only the direct child is killed — grandchildren that outlive it are left to exit on their own (their inherited pipes keep the detached drain threads alive until EOF).
