tamias-deploy — the deploy port: provision a remote registry, plus the shared per-user service spec every local backend renders (systemd units, Task Scheduler tasks, launchd agents, …).

Structs§

ServiceSpec
What to deploy as a per-user service — the platform-neutral spec every local backend (tamias-deploy-systemd, tamias-deploy-windows, tamias-deploy-launchd, …) renders into its own unit/task/plist format. A package’s provider.services[] manifest block supplies the domain data; each backend decides what it can honor (see its crate docs for the per-field mapping and honest gaps).

Traits§

Deploy
A registry deployer — materializes the deployable artifacts (Worker, R2 binding, secret setup) so an operator can ship a hosted registry.
