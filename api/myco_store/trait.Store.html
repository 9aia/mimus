fn item(&self, id: ItemId) -> Result<ItemFile, Error>

Load one item file by id (I-003 → issues/issue-0003-*.md). A same-id file in both live and archive/ is a duplicate-id error. Error::NotFound when absent.

Source

fn save_item(&self, file: &ItemFile) -> Result<(), Error>

Write an item file atomically. Filename derives from the meta (<kind-file-prefix>-<NNNN>-<slug>.md); when the title changed the slug, the old file is removed (rename).

Source

fn remove_item(&self, id: ItemId) -> Result<(), Error>

Delete an item file — archive/remove verbs. Error::NotFound when absent.

Source

fn list_items(&self, kind: ItemKind) -> Result<Vec<ItemFile>, Error>

All item files of a kind, sorted by id. Task items aren’t file-backed — ItemKind::Task yields an empty vec. Archived files (<dir>/archive/) are NOT included.

Source

fn list_archived(&self, kind: ItemKind) -> Result<Vec<ItemFile>, Error>

Item files of a kind under <dir>/archive/, sorted by id — cold storage for done items (myco issue archive).

Source

fn archive_item(&self, id: ItemId) -> Result<(), Error>

Move an item file into its kind’s archive/ subdir. Error::NotFound when there’s no live file; Error::Invalid when it’s already archived.

Source

fn is_archived(&self, id: ItemId) -> Result<bool, Error>

Is id’s file under <dir>/archive/? Archived items stay addressable by Store::item but mutating verbs refuse them (they’d silently un-archive otherwise).

Source

fn item_path(&self, item: &Item) -> Result<Option<String>, Error>

item’s path relative to the store root, in the impl’s own naming grammar (issues/issue-0003-x.md) — including the archive scope (issues/archive/…) when the item is archived, so myco never hardcodes the file spec. Ok(None) for kinds the impl doesn’t file-back (tasks live in TODO.md/BACKLOG.md).

Source

fn index_md(&self) -> Result<String, Error>

index.md verbatim — generated views land later; today it’s a raw passthrough (Error::NotFound when absent).

Source

fn save_index(&self, md: &str) -> Result<(), Error>

Write index.md atomically.

Source

fn read_handoffs(&self, id: ItemId) -> Result<Vec<HandoffEntry>, Error>

handoffs/<ID>.md entries — the live file first, then handoffs/archive/; an empty vec when no file exists.

Source

fn append_handoff(&self, id: ItemId, entry: &HandoffEntry) -> Result<(), Error>

Append an entry to handoffs/<ID>.md — created with the canonical header when absent; lands under archive/ when the file already lives there. Append-only: existing bytes are never rewritten.

Source

fn list_handoff_files(&self) -> Result<Vec<HandoffFile>, Error>

Every handoffs/*.md file (both scopes) — myco check diffs the live set against item ids to spot orphans.

fn kinds(&self) -> &KindTable

The kind table this store resolves against — which prefixes map to dirs, states, and counter keys. Impls default to the compiled-in prelude (zero-config = today’s five kinds); [[kinds]] (P-008) is injected by whoever constructed the store.
