tamias-cache-local — the content-addressed fetch cache: <root>/<key>/ payloads (git-<sha>, sha256-<hex>). Install is fetch→unpack, so a warm cache makes repeat installs and air-gapped nodes free. remove never touches it; eviction is by age or full.
