pub fn hit(&self, key: &str) -> Result<Option<PathBuf>, Error>

Integrity-checked lookup for the install path: Some(entry) only when the entry exists and its payload still matches the digest recorded at commit time. A tampered, unreadable, or pre-metadata (legacy) entry is evicted — dir and meta — and reported as a miss so the caller refetches instead of installing unverified bytes.

§Errors

Propagates failures evicting a rejected entry.

pub fn commit(&self, scratch: &Path, key: &str) -> Result<PathBuf, Error>

Fold a filled scratch dir into entry(key) — an existing verified entry wins (the scratch is discarded); a corrupt or legacy one is evicted and replaced by the fresh fetch. Either way the committed entry carries integrity metadata, so later FetchCache::hits can prove the payload is what was fetched.

§Errors

Fails on an invalid key, an unreadable scratch payload, or an I/O error writing metadata/renaming.
