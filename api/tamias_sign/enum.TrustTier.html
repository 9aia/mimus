Enum TrustTier 

Source 
pub enum TrustTier {
    Official,
    Signed,
    Pinned,
    Unpinned,
    Bad,
}
Expand description

The trust tier a package’s provenance earns — the badge tamias verify and install records report (P-005 §A). Highest wins:

  • TrustTier::Official — signature present and verified against policy.official_signers.
  • TrustTier::Signed — signature present and verified against policy.allowed_signers, but not the official set.
  • TrustTier::Bad — signature present and verification failed against every configured signers file. A failed signature must never display as merely unsigned.
  • TrustTier::Pinned — no verifiable signature, but source_ref carries an integrity pin (see [ref_is_pinned]).
  • TrustTier::Unpinned — everything else: a moving git branch/tag, bare http(s), fs paths.
