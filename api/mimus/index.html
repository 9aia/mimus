mimus — the engine as a library. Everything that used to live in the binary lives here: Cli/Cmd, claim extraction, the check/fix/report/audit/doctor/coverage/claims pipeline. run() is the compat CLI’s whole body; drivers (mimus bin, tamias-driver-mimus run) split it into parse/parse_from

  • dispatch — argv in, exit code out, ops callable as dispatch(&cli).

mimus — spots the cuckoo eggs in your repo. Composition root: parses mimus.toml, wires checker adapters, runs subcommands.

command
The clap verb tree as a [clap::Command] — the ops manifest derives itself from this, so a verb can’t exist on the CLI and be missing from the driver’s wire surface.
dispatch
One parsed command → exit code. The dispatch every driver shares; argv parsing is a caller concern.
parse
Process argv → a parsed Cli. Split from dispatch so drivers can parse their argv (a run verb, a re-exec) without owning process args. Clap errors/help still exit the process, same as argv parsing.
parse_from
Same, from an argv iterator — parse_from(["mimus", "audit"]).
run
The compat CLI body — parse argv, dispatch, hand back the code.
run_from
Same, from an argv iterator — the run passthrough entry drivers re-exec (tamias-driver-mimus run <mimus argv>).
