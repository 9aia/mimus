Enum ServiceBackend 

Source 
pub enum ServiceBackend {
    Systemd(LocalDeploy),
    Tasks(WindowsDeploy),
    Launchd(LaunchdDeploy),
}
Expand description

The per-user service backend for this host — systemd --user units on Linux/Unix, Task Scheduler per-user tasks on Windows, launchd gui/<uid> agents on macOS. All render the same [ServiceSpec] from the tamias-deploy port; ServiceBackend::new picks by cfg! once, so callers never branch on platform themselves.

pub fn logs_with( &self, names: &[String], lines: u32, follow: bool, ) -> Result<(), Error>

Journal/log tail over one or more services — journalctl on systemd; tail over the agent’s stdout/stderr log files on macOS launchd; best-effort schtasks /query snapshots on Windows (Task Scheduler keeps no per-task log; lines/follow are ignored there).

§Errors

Error::Failed on an empty/invalid name list; propagates the backend failure.

Source

pub fn log_stream( &self, names: &[String], lines: u32, follow: bool, ) -> Result<(String, Vec<String>), Error>

The (program, argv) a streaming surface spawns to tail logs — journalctl on systemd; tail -f over the agent’s log files on macOS launchd; on Windows a schtasks /query snapshot (cmd /c-chained for several tasks; follow/lines have no meaning — there is no log stream to follow).

§Errors

Error::Failed on an empty/invalid name list.
