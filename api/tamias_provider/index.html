tamias-provider — the provider lifecycle shared by tamias (CLI verbs) and tamias ui (the Services pane). Everything here used to live private in tamias-cli: resolving an installed package’s provider: block into unit/task names, host-backend state probes (systemd systemctl / Windows schtasks / macOS launchctl via ServiceBackend), deploy/uninstall teardown (driver verb + declarative units + shared-unit survivor re-render), the foreground run exec spec (env_file → env → workdir, the same order the unit renders), and the journal unit list logs tails.

Nothing shells out to the tamias binary and nothing re-parses CLI output: callers get typed rows/specs/reports and do their own rendering (println, ratatui, serve JSON).

DeployReport
A deploy/uninstall outcome split by destination stream — lines are the normal report (stdout), warnings the advisory notes (stderr). Both UIs print/log them verbatim.
ExecSpec
What a foreground run needs — the resolved argv/env/workdir the unit would render, minus systemd. Callers spawn it themselves (tamias run inherits stdio; tamias ui pipes + streams).
ProviderPackage
One installed package’s provider view — None provider means the package declares no provider: block (only surfaced by callers that asked for all packages, like provider list --all).
ProviderView
The renderable bits of a provider: block.
ServiceRow
One provider service as the Services surfaces show it — package label, service name, unit base name (<provider>-<service>), systemctl is-enabled state when systemd answers, and the declared exec line.

Enums§

ServiceBackend
The per-user service backend for this host — systemd --user units on Linux/Unix, Task Scheduler per-user tasks on Windows, launchd gui/<uid> agents on macOS. All render the same [ServiceSpec] from the tamias-deploy port; ServiceBackend::new picks by cfg! once, so callers never branch on platform themselves.
UnitAction
A systemctl --user lifecycle verb on a unit base name.

Functions§

deploy
deploy <name> — the installed package’s provider deploy step: the kind driver’s deploy verb and, independently, every provider.services[] entry rendered as a per-user systemd unit. Units are written + daemon-reloaded but not enabled.
exec_spec
run <pkg> [service] [-- args…]’s resolved exec — the provider service’s argv (plus extra), env (env_file parsed as K=V lines, inline env overriding — the same order systemd applies), and workdir (~ expanded, else the payload dir). This is the no-systemd counterpart of the rendered unit.
list
Every installed package’s provider view, in store order — provider list’s data source. Packages without a provider: block come back with provider: None (callers filter for --all-style output).
provider_base
The provider display/identity base — provider.name, else the scope-qualified package name (shared by unit_name and list).
service_rows
The flat service table the Services pane selects from — one row per (package, provider service) pair.
uninstall
uninstall <name> — provider teardown + drop the store entry: driver uninstall first (a failing driver keeps the store entry), then declarative units are removed unless a surviving installed provider still declares the same unit name — that unit is re-rendered from the survivor’s spec instead.
unit_action
A host-backend lifecycle verb on a unit/task base name — tamias service enable|disable equivalents plus start/stop/ restart for the interactive surfaces.
unit_name
The unit base name a provider service renders to — <provider-or-package>-<service>. Deterministic: two packages claiming the same unit name resolve last-deploy-wins on the unit file.
unit_state
Best-effort host-backend state probe — systemctl --user is-enabled <unit> on Linux/Unix, schtasks /query on Windows, launchctl print gui/<uid>/<label> on macOS; bounded at 3s, None when the backend can’t answer (no user bus, missing schtasks/ launchctl, timeout). Exit statuses don’t map cleanly to “enabled” on any backend, so the state is read from stdout (stderr as fallback), not the exit status.
units_of
The unit base names an installed package’s provider declares — logs’ unit list. Errors when the package has no provider: block or declares no services.
unquote_env
Strip one layer of matching surrounding quotes from an env_file value — systemd unquotes KEY="a b"/KEY='a b' the same way.
