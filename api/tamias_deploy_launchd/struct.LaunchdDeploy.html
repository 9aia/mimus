pub fn install(&self, spec: &ServiceSpec) -> Result<PathBuf, Error>

Write the plist (+ wrapper script and empty log files when env_file is set / always for logs). Does not load the agent — enable bootstraps it (systemd’s write-unit vs enable --now split).

§Errors

Error::Failed on an invalid name/spec field, an empty exec argv, or a write failure. On non-macOS the default runner is never reached — install is pure file rendering, so it succeeds anywhere (verbs are what fail off-macOS).

Source

pub fn daemon_reload(&self) -> Result<(), Error>

No-op kept for parity with the other backends: launchd has no daemon-reload — bootstrap reads the plist at load time, and enable re-bootstraps after edits.

§Errors

Never — always Ok.

Source

pub fn enable(&self, name: &str) -> Result<(), Error>

launchctl enable <target> (clears a persisted disabled override, best-effort), launchctl bootout <target> (best-effort — unloads a loaded agent so bootstrap below can’t fail “already loaded”), then launchctl bootstrap gui/<uid> <plist>.

Re-enabling an already-loaded agent restarts it — launchd has no enable-without-reload (documented gap).

§Errors

Error::Failed on an invalid name or a missing plist path; propagates the bootstrap failure.

Source

pub fn disable(&self, name: &str) -> Result<(), Error>

launchctl bootout gui/<uid>/<label> (best-effort — a service that was never bootstrapped must not fail disable) then launchctl disable gui/<uid>/<label> — the persistent per-domain override, so the agent stays off across logins (systemd disable parity).

§Errors

Error::Failed on an invalid name; propagates the launchctl disable failure.

pub fn logs_with( &self, names: &[String], lines: u32, follow: bool, ) -> Result<(), Error>

tail -n <lines> [-f] <stdout.log> <stderr.log>… over one or more agents — launchd writes the log files itself, so unlike systemd there is no journal to query, just files to tail. follow adds -f (blocks like journalctl -f).

§Errors

pub fn uninstall(&self, name: &str) -> Result<(), Error>

Best-effort bootout + clear-any-disabled-override + remove the plist, wrapper, and log files. A missing agent must not fail uninstall.
