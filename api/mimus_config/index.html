Source
Expand description

Config port + file impl — mimus.{yaml,yml,toml} loading through scarab-config’s file discovery (P-017): explicit --config → $MIMUS_CONFIG → ./mimus.* (YAML preferred) → ~/.config/mimus/. The generic machinery is scarab’s (scarab-config-file); this crate is only the wiring plus the ConfigSource port front-ends bind. The retired mimus-config-toml crate’s hand-rolled search lives here now.
