myco-index-redb — the redb impl of [myco_index::Index].

Layout under the index dir ($MYCO_HOME, else $XDG_DATA_HOME/myco, else ~/.local/share/myco):

  • index.redb — the snapshots table (canonical repo path → JSON [RepoSnapshot]) plus the link-index tables (P-005): files (repo\0rel → JSON [FileStamp]), file_edges (repo\0rel → JSON edge set — the provenance that makes a file’s outgoing edges swappable), edges (multimap repo\0src\0kind → dst), and rev_edges (multimap repo\0dst → kind\0src) for O(1) related.
  • repos.toml — the registry ([[repo]] path name), kept as a plain file so it stays human-inspectable.

Everything here is a derived cache — rm -rf the dir and myco index rebuild derives it back from the worktrees.

data_dir
The index dir: $MYCO_HOME → $XDG_DATA_HOME/myco → ~/.local/share/myco. The $MYCO_HOME override is how tests (and unusual setups) relocate the whole cache. Err when no base resolves (HOME unset) — better than writing the cache into whatever directory myco happened to run from.
