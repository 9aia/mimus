myco_index

Source
Expand description

Link index — the edge cache behind “what is attached to item X?” (P-005). A second index face next to the repo snapshots: project/ files are the input signals, (src, dst, kind) edges the memoized output.

Invalidation is file-grained: each file’s FileStamp pairs the mtime+size precheck with a content fingerprint (xxh3). On reload the caller diffs live files against LinkIndex::stamps, re-derives edges for the dirty set only (myco_core::refs::extract is pure), and LinkIndex::record swaps that file’s outgoing edges + stamp in one txn — a crash mid-sync can never leave a file half-updated. LinkIndex::sweep drops records whose source file vanished; dangling edge ends are filtered per query by the caller’s alive set.
