Expand description

The link-index face of the port — per-repo edge storage.

repo is the same key Index snapshots use (the canonical repo-root path); edges from different repos never mix. All methods are &self: impls open the backend per call, like the snapshot face does.

Required Methods§

fn stamps(&self, repo: &str) -> Result<BTreeMap<Utf8PathBuf, FileStamp>, Error>

Every file stamp recorded for repo — the precheck input for the invalidation diff.

Source

fn record( &self, repo: &str, rel: &Utf8Path, stamp: &FileStamp, edges: &[Edge], ) -> Result<(), Error>

Replace rel’s outgoing edge set + stamp atomically — one txn, so a crash can never leave a file half-updated. edges is the whole set extract derived for this file (possibly empty — a stamp with no edges is how “file read, nothing declared” is recorded).

Source

fn restamp( &self, repo: &str, rel: &Utf8Path, stamp: &FileStamp, ) -> Result<(), Error>

Update only the stamp — content matched (fingerprint equal) but mtime moved; keeps the next precheck cheap without touching edges.

Source

fn related( &self, repo: &str, id: ItemId, alive: &BTreeSet<ItemId>, ) -> Result<Vec<Related>, Error>

Everything attached to id, both directions — outgoing edges come back verbatim, incoming ones with kind mirrored (blocks → blocked_by). Edge ends not in alive are dropped here, at query time — dangling ids are cheap to filter and get compacted away on the next sweep. Sorted by (kind, other).

Source

fn reach( &self, repo: &str, id: ItemId, kind: EdgeKind, max_depth: usize, ) -> Result<Vec<ItemId>, Error>

Forward reachability from id along kind edges, at most max_depth hops — the visited set makes cyclic input terminate (the graph tolerates cycles, per the proposal; nothing enforces acyclicity). Sorted, id itself excluded.

Source

fn sweep( &self, repo: &str, live: &BTreeSet<Utf8PathBuf>, ) -> Result<usize, Error>

Delete every record whose source file isn’t in live — stamps, provenance, and the edges they carried. Returns the number of files removed.

fn dirty( &self, repo: &str, live: &BTreeMap<Utf8PathBuf, FileStamp>, ) -> Result<Vec<Utf8PathBuf>, Error>

Which live files need re-deriving — new paths plus stamps that differ. Default impl diffs against stamps; impls may override for a fused backend query.

Source

fn purge(&self, repo: &str) -> Result<(), Error>

Drop all link records for repo — the index remove teardown. Default impl sweeps with an empty live set.
