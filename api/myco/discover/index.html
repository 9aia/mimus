Module discover 

Source
Expand description

Re-export — lives in myco_ops::discover so other front-ends (myco-driver) share it. discover itself is cli-local: ops takes the config loader as a parameter and the composition root (this crate) names the impl, so call sites stay two-arg.

The cli discover adds the org-ledger fallback on top of ops’ strict discovery: inside a registered repo with no ledger of its own, verbs resolve to the ledger = "org" entry’s worktree. The index opens lazily — only when plain discovery already failed — so the happy path never touches it, and unregistered repos fail exactly as before.
