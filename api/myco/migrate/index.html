myco migrate — bring legacy ledgers to the v2 schema.

Two modes, auto-detected:

  • pm/ → project/ — a pm/ dir at the repo root is the pre-worktree layout. TODO.md/BACKLOG.md bullets become T-items, ROADMAP.md becomes a plans/ file, any other *.md becomes an issue; the pm/ dir is removed and its deletion committed on the current branch.
  • legacy project/ → v2 — files already on the project branch are normalized in place: id-less items get ids, [x]/done items drop, heading-like lines become sections, frontmatter-less files in item dirs are adopted (the filename’s number is honored when free — 0001-foo.md → ADR-0001 — collisions take the next unclaimed number with a warning; synthesized frontmatter + canonical name), everything re-emitted canonically.

Either way, bullet shapes the target doc can’t express demote to plain-task text with a warning instead of failing the run — a status:deferred in TODO.md folds into the title, a self-block drops, a textless ## merges into the section before it ([demote]).
