myco status [--prompt] — the ledger digest; THE agent-context verb. Human output is compact counts + the in-progress and blocked lists; --prompt is a token-sized block (repo, counts one-liner, then items grouped in-progress → blocked → claimed → open-by-priority, one per line, no prose); --json is the structured digest — with --prompt it’s {"prompt": "<block>"}.

PROMPT_MAX_LINES
Hard cap on --prompt lines — the block must stay token-cheap.

prompt_block
The --prompt block, hard-capped at PROMPT_MAX_LINES. Sections render in spec order (in-progress → blocked → claimed → open); when the block overflows, items are cut from the last non-empty group first — open (always largest) absorbs the budget, then claimed/blocked, with in-progress dropped last. A truncated group keeps a … +N more <name> marker; a fully cut group disappears (the counts line still summarizes it).
