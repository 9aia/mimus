The interrupt write — a session ended with work still claimed/in-progress/blocked. Reverts the item to open through the shared item set mutation path (relocation rules included) and appends the interrupted marker entry. Caller commits — one commit covers both writes.

session scopes as well as tags: when passed, the item’s claim must be held by that session (claim_session) — interrupt <id> --session <s> can’t clobber a claim it doesn’t own. Without session the interrupt is unconditional (the escape hatch).
