myco handoff / myco resume / myco interrupt — the continuity trio. At session end handoff appends a ## <today> · <actor> entry plus note to handoffs/<ID>.md (append-only, one file per item, uniform across kinds). At session start resume emits the minimal restart context — the item, its blocks: dep titles, the latest handoff entries, the open checklist — sized for a prompt, the single-item counterpart of status --prompt. interrupt is the abnormal end: a work-state item (claimed/in-progress/blocked) reverts to open and gets an interrupted handoff in one commit.

sepia owns session lifecycle; it calls these verbs from hooks. --session <id> is the hook contract: handoff/interrupt tag their entry with it, and the claiming verbs (next --claim, item set) record it as a claimed handoff entry — the tag lives in the entry heading (session:<id>), no item field. An item is “claimed under” a session when its latest session-tagged handoff entry names it (claim_session); interrupt --session <id> (no item id) is the teardown — every live work-state item that session last tagged reverts in one commit, so a dying session releases exactly its own work.

Constants§

CLAIM_NOTE
The note the claim-side verbs write when --session tags a claim (next --claim, item set on a work-state item) — the session:<id> heading is the tag interrupt --session filters on; the note is for humans reading the log.
INTERRUPT_NOTE
The note prefix interrupt writes — also the derivation rule: an item “was interrupted” when its latest handoff note starts with this word. No dedicated status — the event lives in the append-only log; status/board/report surfaces derive the flag.

Functions§

claim_session
Which session holds the item’s claim — the session: of its latest handoff entry that carries one. An untagged entry is anonymous: it neither claims nor transfers; another session’s tagged write does. None = no session ever declared one.
h_handoff
The handoff verb — - reads the note from stdin.
h_interrupt
The interrupt verb — called by whoever owns session lifecycle (sepia hooks, CLI session-end hooks); myco never detects sessions itself. With an id it reverts that one item (--session asserts the claim is that session’s); without an id, --session <id> is the teardown — every item claimed under the session reverts in one commit.
h_resume
The resume verb — 1..n ids, one discover + store open. --json is the single-id payload for one id, else the [{id, ok, payload|error}] batch array. Human output is the prompt block per id in argument order; a bad id reports to stderr and exits 1 without aborting the rest. The resume verb — 1..n ids, one discover + store open.
interrupt_item
The interrupt write — a session ended with work still claimed/in-progress/blocked. Reverts the item to open through the shared item set mutation path (relocation rules included) and appends the interrupted marker entry. Caller commits — one commit covers both writes.
interrupt_session
interrupt --session <s> — the bulk teardown. Every live work-state item whose claim claim_session reads as session’s reverts + marks. Caller commits once for the whole sweep — a malformed handoff or failed revert reports per item and doesn’t abort the rest.
interrupted_set
The interrupted subset of items — for status/board markers. The first unreadable handoff file fails the set.
is_interrupted
Did the item’s latest handoff mark it interrupted? A read failure propagates — a malformed handoff file is a finding, not a silent “not interrupted”.
record_handoff
The handoff write — the item must exist somewhere in the ledger (any kind, live or archived). Validates the note and the session id, appends the entry, and returns it plus the worktree-relative path (the file lands wherever it already lived). actor is the resolved actor (ops::resolve_actor — callers fold --actor in first). Caller commits.
resume_json
The resume payload — {item, location, blocks_titles, links_titles, handoffs[], open_checklist} — shared by --json and myco serve.
