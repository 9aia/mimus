myco todo add|done|defer|list — task items in TODO.md.

Functions§

add_item
The todo add mutation — allocs a T-id and appends to TODO.md (or nests under --parent; a backlog parent’s child parks with it). The parent is validated before the id is allocated so failed adds don’t burn ids. Returns the new item plus the doc it landed in. Caller commits.
cancel_item
The todo cancel mutation — walks to cancelled, removes the line (subtree included), and archives the subtree into DONE.md with the cancelled status preserved (unlike done, the archive records why it left). Works on BACKLOG.md items too — cancelling parked work shouldn’t require promoting it first. Caller commits. Returns the removed item.
defer_item
The todo defer mutation — walks to deferred, moves the line (subtree included) into BACKLOG.md. Caller commits.
doc_items
All items in one doc, cloned out (shared by the list verbs).
done_item
The todo done mutation — walks to done, removes the line (subtree included), and archives the subtree into DONE.md. Caller commits. Returns the removed item.
