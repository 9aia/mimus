The board chrome — the columnar card renderer behind myco view’s board format (repo- and index-sourced alike).

A status-grouped spec earns the lane chrome: capitalized lanes Backlog | Open | Claimed | In Progress | Blocked (deferred leads as backlog; done items leave the ledger, so there’s no Done column), backlog-first order, and the five-lane columns-map --json. Any other grouping renders generic columns headed by the group labels. --md is the same board as a markdown table for embedding in docs.

Fit
Human-render constraints for the board — width budget + row cap. --md/--json use Fit::UNBOUNDED; caps are a terminal concern only.

Constants§

COLUMNS
Column order — a deferred item is a backlog item wherever it lives, and the terminals (done/cancelled) have no column — they archive into DONE.md.
DEFAULT_MAX_ROWS
Default cap on board rows for human output (--all lifts it) — a screenful, so a huge ledger can’t bury the terminal.
