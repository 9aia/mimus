Module serve 

Source
Expand description

myco serve — a sequential request/response verb surface for embedding: an orchestrator (peregrin) spawns one long-lived process per repo instead of one spawn per verb. A single process serializes writes — no index.lock races — and the store is re-opened per request, so the served process always sees on-disk truth.

Two abstractions keep the surface honest: ServeTransport moves one raw line in and out (stdio first; a unix socket can slot in untouched), and WireProtocol frames requests and responses (JSON-RPC 2.0 first — the default, not the spec). Server::dispatch is the verb surface itself and knows neither. stdin IS the wire — no served method reads content from it. myco batch drives the identical surface one-shot through Server::handle_line — NDJSON in, NDJSON out.
