pub fn repo_at(path: &Path) -> Result<Project, String>
Expand description

<path> → the repo root + project worktree. Accepts a repo root (<path>/project must qualify), the worktree itself, or — for index add’s ledger-less path — any dir inside a git repo (the returned worktree is the conventional <root>/project, which may not exist; callers check discover::qualifies). --dir discovery doesn’t qualify its path, so the check is repeated here — index add on a plain dir must fail.

Both paths come back canonicalized — root keys the registry and snapshots, so symlinked aliases of one repo must collapse to a single entry (remove/rebuild canonicalize too).
