Expand description

One declared param — CLI flag/positional and wire key. Fields are pub so the table reads as data; the const builders keep entries terse.

Fields§

§name: &'static str

The canonical name — clap gets --name (_ → -), the wire gets the "name" key.

§help: &'static str

Help text.

§kind: PKind

Pos / Flag / Opt.

§val: Val

The value type.

§on: On

Which front-ends see it.

§multi: bool

Repeatable / multi-value (CLI num_args, wire array).

§delimited: bool

Comma-separated values also accepted (CLI).

§hyphen: bool

Values may start with - (CLI).

§required: bool

Positionals are required by default; opts/flags aren’t.

§default: Option<&'static str>

A baked default (--to backlog).

§short: Option<char>

A short flag (-m).

§alias: Option<&'static str>

A visible alias (--priority for --pri).

§conflicts: Option<&'static str>

Mutually exclusive param name.

§vname: Option<&'static str>

value_name in help.
