myco reap — the bulk stale-claim reaper. A scheduler (peregrin campaign, a cron’d myco batch) calls it periodically: every live claimed/in-progress item whose last activity — the latest handoff entry’s date, else created — is older than --idle-days (default report::STALE_CLAIM_DAYS, the same threshold report’s stale-claims finding uses) reverts to open with an interrupted handoff — exactly myco interrupt <ID>, batched: per-item failures are collected, the rest still land, and the whole sweep is ONE commit (chore: reap N stale claims). --session <id> scopes to items whose claim tag names that session (the continuity::claim_session rule interrupt --session uses); --dry-run lists the sweep with zero writes.

Functions§

apply
The mutating half — each hit through continuity::interrupt_item (the same status revert + interrupted marker), the item’s own claim session carried through so the marker stays tagged and a claim that moved between plan and apply can’t be clobbered. Per-item failures are collected — the rest still land. Caller commits once for the whole sweep.
h_reap
The reap verb — scheduler-facing bulk interrupt. One commit covers the whole sweep; zero matches is a clean no-op (no commit, committed: false).
idle_threshold
--idle-days → the threshold — absent means the report’s stale-claim constant; Val::Count already bounds it to u64, so the i64 conversion only fails past i64::MAX.
payload
The --json/wire payload — {"reaped": [{id,title,owner, session,idle_days}], "errors": [{id,error}], "dry_run": bool, "committed": bool}.
plan
The scan half — live claimed/in-progress items whose last activity is older than idle_days, optionally scoped to one claim session. Pure read: no writes, safe for --dry-run.
report
Shared result rendering — the --json payload or the human block; per-item errors go to stderr either way. Returns the exit code (1 when any item errored — the reverts still committed, same rule as interrupt --session).
