myco report — aging + velocity + blocked, the “how is the ledger trending” view.

Aging buckets active items by created age (<7d / 7-30d / >30d; undated items are counted apart). Velocity replays the project-branch history: chore: done|resolve <id> subjects are completions, chore: add|new … are creations — grouped per ISO week. Done items leave the files, so git is the only place that history still exists.

STALE_CLAIM_DAYS
Days idle before an in-progress item counts as a stale claim — the no-hook safety net: nobody called myco interrupt, but work clearly isn’t moving. Claimed items are excluded — parking a claim is legitimate; in-progress idle is a leak.
