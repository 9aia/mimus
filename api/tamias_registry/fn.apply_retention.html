pub fn apply_retention(
    entries: &mut Vec<RegistryEntry>,
    keep: usize,
    published: &RegistryEntry,
) -> Vec<String>
Expand description

Apply a retention policy to entries after published joined the index — the pure core both registry adapters share (P-024).

Only the published package’s (scope, name) group is touched. Within it, versions that parse as semver order descending — prereleases count in the same ordering (1.0.0-rc.1 sorts below 1.0.0), publish order is irrelevant — and only the keep most recent stay indexed, plus published itself (never pruned, even when it sorts outside the window — e.g. re-publishing an old version). Entries with no version or a non-semver version can’t be ordered, so they’re always kept and don’t count toward keep. keep = 0 keeps only the published version. Returns the labels of the pruned entries, sorted for stable reporting.
