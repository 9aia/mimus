Getting started ​

Pick by what you need to do.

  • Tutorials (learn): first-run
  • How-to (tasks): memory audit · rules authoring
  • Reference (lookup): cli · config · crate api
  • Explanation (why): architecture · release model · comparison — vs linters / LLM review

Install:

sh
cargo install --git https://github.com/9aia/mimus mimus

First check:

sh
cd your-repo
mimus init    # detect claim sources -> mimus.toml + rules/
mimus check   # mechanical tier: paths, commands, symbols
mimus report  # violations with claim + evidence + fix

symbol claims, audit, and coverage need a kuda index (kuda sync) — without one, the mechanical tier is paths + commands + rules.
