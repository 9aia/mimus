Top level ​

fieldtyperequirednotes

[sources] ​

fieldtyperequirednotes
docslistoptionalDoc glob patterns mined for claims.
commentsbooloptionalExtract claims from code comments too.
cardsstringoptionalGlob for memory cards to audit (empty = skip).

[check] ​

fieldtyperequirednotes
mechanicalbooloptionalMechanical tier — deterministic, CI-gateable.
semanticbooloptionalSemantic tier — advisory only, can never gate.
kuda_indexpathoptionalkuda index path for the symbol checker.

[rules] ​

fieldtyperequirednotes
dirpathoptionalDir of *.toml rule files.
strictbooloptionalRule violations also fail check (not just report).

[report] ​

fieldtyperequirednotes
formatstringoptional"human" | "json".
min_confidencestringoptionalSuppress low-evidence findings ("high" | "all").

Constraints ​

  • queue = "all" rejects cancel_running = true at load — killing a run would silently drop a promised commit.
  • runner.kind and trigger.kind/status.kind resolve to impl crates; unknown kinds fail at mimus doctor/startup.
  • deny_unknown_fields: typos in field names fail the load.
